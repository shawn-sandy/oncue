Core finding

Colours fit; the look lives in hard-coded traits

Astro Kit's colours map onto OnCue's 13 roles with every contrast pair passing, but its look lives in traits OnCue hard-codes (2px borders, 800 headings), so a colours-only preset would repaint today's shapes. A distinct default needs a preset file plus two new theme tokens, stroke and weight.
  • scenes.ts has 98 CSS rules; 27 use only literal px and 92 px values are fixed in total.
  • Fixed today: 2px borders on cards, bubbles, player, tiles and photos; weight 800 on headings, panel titles and step numbers; 999px pills; circular icons.
  • No colour or font defaults exist in the engine; when nothing is found, the storyboard skill invents a palette.

    Approach · 2026-11-10Preset file plus two look tokens. The only option that renders a look distinct from today's while keeping new themes to one file.
  2. 2
    Settled beforeUnset keys keep today's look. stroke defaults to bold, weight to heavy; specs without them render byte-identical output.
  3. 3

  4. 4
    Settled beforeThe Gleaner example keeps its own brand. The default applies to new Shorts with no look.
  5. 5
    Review · 2026-11-10The storyboard skill copies the preset in. Colours, fonts, deck fonts and theme go into short.json; the product keeps its own name and logo. No merge code in the engine.
  6. 6
    Review · 2026-11-10Light by default. Astro Kit's primary theme; the word "dark" picks the dark mode.
  7. 7
    Review · 2026-11-10Inter for sans, JetBrains Mono for mono. Inter is added; JetBrains Mono is already installed.
  8. 8

Workstreams and roadmap

What gets built, in order

Phase 1 · M

A. Two new theme tokens

  • stroke: bold (2px, default) or hairline (1px).
  • weight: heavy (800, default) or semibold (600).
  • Type, validation, both renderers, spec.md, rebuilt dist/.
  • Tests extend the existing theme loop; default output stays byte-identical.
Phase 2 · S

B. The Astro preset file

  • engine/themes/astro.json with light and dark modes.
  • Add @fontsource/inter.
  • A test runs every theme file and mode through the contrast check, so a new theme is safe to drop in.
Phase 3 · S

C. Skill prose

  • Storyboard step 1 copies the Astro default instead of inventing a palette.
  • theme.md gains "Default theme" and "Making a new theme".
  • Plain words can set stroke and weight; the DESIGN.md oncue: block stores both.
Phase 4 · S

D. Release

  • Version 1.8.0 to 1.9.0, changelog entry.
  • Render the example deck and stills in both modes and look at them.

Risks

Where it could strain

  • 1px lines in compressed video. H.264 may soften a hairline. If stills look broken, hairline becomes 1.5px, decided from a real frame.
  • Pills and circles stay. Astro Kit avoids pills, but tags, timestamps and icon dots keep their shape. Out of scope for now.
  • Accent equals highlight. One teal for everything reads calmer than today's two colours. That is the intent; confirm on the stills.
  • One more font package in every project's engine copy.
