This is a research file for short explainer videos about the tool described in a README.

PASS if the file contains a ranked (numbered or otherwise ordered) list of 3, 4 or 5 topic ideas, and every one of those topics has all three of: a hook line (an opening sentence a narrator could say), an audience (who the video is for), and a source that names a section or heading of the README (for example "README, Usage" or "README: How it works").

FAIL if there are fewer than 3 or more than 5 topic ideas, if they are not ranked, or if any topic is missing a hook line, an audience, or a README section as its source.
